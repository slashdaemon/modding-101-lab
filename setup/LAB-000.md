# Lab 000 · Set up IntelliJ IDEA

Every Lab comes as a jar you can play and a zip of the whole project. This guide gets the project open in
IntelliJ IDEA so you can read the code, change it, and start Minecraft with your change in one click. It
works the same for every Lab; you only install things once.

**What you need**
- A Windows PC or a Mac, and about 5 GB of free disk space (IntelliJ, Java 21, and Minecraft's files).
- An internet connection the first time you open a Lab (Gradle downloads Minecraft and Fabric).
- You do **not** need to buy anything, own a JetBrains account, or install Java yourself: the first time you open
  a Lab, it fetches the Java it needs (Java 21) on its own.

## 1. Install IntelliJ IDEA

Download it from **jetbrains.com/idea/download**. IntelliJ IDEA is free; the paid "Ultimate" features are
optional and nothing in the Lab needs them.

- **Windows:** run the downloaded `.exe` and keep the defaults.
- **Mac:** pick the download for your chip (Apple menu > About This Mac: "Apple M…" is **Apple Silicon**,
  "Intel" is **Intel**), open the `.dmg`, and drag IntelliJ IDEA into **Applications**.

Start it and accept the user agreement. It may say a 30-day trial of the paid features has started: you
don't need to buy anything. When the trial ends, IntelliJ keeps working with its free features, and those
cover everything in the Lab.

## 2. Add the Minecraft Development plugin

On the welcome screen, click **Plugins** in the left column, open the **Marketplace** tab, search for
`Minecraft Development`, click **Install**, then restart IntelliJ when it asks.

(With a project open, the same place is **File > Settings > Plugins** on Windows and
**IntelliJ IDEA > Settings > Plugins** on a Mac.)

The plugin is optional, but it marks Fabric's files with icons and understands mixins, which start in Part 3.

## 3. Unzip a Lab

Make a folder for the Lab whose path has only plain English letters and numbers (no accents, no emoji):
build tools break on other characters.

- **Windows:** make `C:\ModdingLab`. Right-click the Lab's zip, choose **Extract All…**, and extract it
  into `C:\ModdingLab`. You get `C:\ModdingLab\m101-001-hello`.
- **Mac:** double-click the zip in Downloads; it unpacks to a folder. Move that folder into a new
  `ModdingLab` folder in your home folder (Finder: **Go > Home**).

The folder to open is the one with `build.gradle` inside it.

## 4. Open it

On the welcome screen click **Open**, choose the Lab's folder (`m101-001-hello`), and click **OK** (Windows)
or **Open** (Mac). When IntelliJ asks whether to trust the project, choose **Trust Project**.

## 5. Wait for the first sync

The first time, Gradle (the build tool every Lab uses) downloads Java 21, Minecraft and Fabric and prepares them.
The bar at the bottom of the window shows progress; it takes a few minutes. Later Labs reuse the same files and
open much faster.

## 6. Start Minecraft

At the top of the window, the run list now shows **Minecraft Client**. Click the green **Run** triangle next
to it. Minecraft opens with the Lab's mod installed, under a test player name (no Minecraft login needed).

The **Run** panel at the bottom shows the game's log. For Lab 001, look for:
`Hello from Modding 101! Lab 001 is loaded.`

Stop the game with the red square, or quit from the game's menu.

## 7. Read the code (the reason we're here)

- The Lab's own code is in the **Project** panel on the left: `src > main > java > …`.
- **Ctrl+click** (Mac: **Cmd+click**) any name to jump to where it's defined, including Fabric's and
  Minecraft's classes. Try `ModInitializer` in `HelloMod.java`.
- To read Minecraft's own code with proper names, run the **genSources** task once: in the Gradle panel,
  **Tasks > fabric > genSources** (double-click). After that, when you open a Minecraft class and see a
  banner offering sources, click **Choose Sources…** and pick the file whose name ends in `-sources.jar`.

## 8. Change something

Edit the log line in `HelloMod.java`, then click **Run** again. Your change is in the game. That's the loop
for every Lab: read, change, run.

## If something goes wrong

| You see | Do this |
|---|---|
| No **Minecraft Client** in the run list | Open the Gradle panel (the elephant on the right edge) and click **Reload**; it appears when the sync finishes. |
| The sync fails while downloading | Check your connection and click **Reload**; it picks up where it stopped. |
| Gradle says it cannot find a Java installation matching version 21 | Gradle couldn't download Java 21 (often a school or work network). Install Java 21 from **adoptium.net**, then **Reload**. |
| Errors mentioning a path with odd characters | Move the Lab folder somewhere with a plain path (step 3). |
| Mac: `permission denied: ./gradlew` (only from the Terminal) | Run `chmod +x gradlew` in the Lab folder once. |

**Using the Terminal instead?** Every Lab also builds with `./gradlew build` (Windows: `gradlew build`), and
`./gradlew runClient` starts the game. Any Java will start Gradle; it fetches Java 21 for the build itself. With no
Java at all, install Java 21 from adoptium.net first.
